# 资产圣经：角色、场景、道具

一致性不是靠提示词祈祷，是靠**一套编号、一套光、一套参考图**。资产没锁，后面每一段都在抽卡。

## 资产目录

```
项目目录/assets/
├── characters/
│   ├── CH_SY_face_v01.png
│   ├── CH_SY_front_v01.png
│   ├── CH_SY_side45_v01.png
│   ├── CH_SY_expr_neutral_v01.png
│   ├── CH_SY_expr_angry_v01.png
│   ├── CH_SY_expr_broken_v01.png
│   ├── CH_SY_wardrobe_a_v01.png
│   └── CH_SY_wardrobe_b_v01.png
├── scenes/
│   ├── SC_CT_master_v01.png
│   ├── SC_CT_reverse_v01.png
│   └── SC_CT_detail_v01.png
├── props/
│   ├── PR_LETTER_v01.png
│   └── PR_LETTER_hand_v01.png
└── manifest.json
```

命名规则：

- `CH_` 角色，`SC_` 场景，`PR_` 道具。
- 中间 2–3 位拼音首字母，如 `SY` = 沈砚，`CT` = 祠堂。
- 类型：`face/front/side45/expr_*/wardrobe_*/action`。
- 版本：`v01` 起，改一次加一版，不覆盖旧版。
- 文件名只用小写字母、数字、下划线，避免中文路径在脚本里出问题。

## 角色资产：先脸，后全身，再表情

一次性生成“三视图”很容易三张脸不一样。正确顺序：

### 1. 定脸（canonical face）

```
角色定妆照，中国女性，28 岁，鹅蛋脸，眉眼清淡，鼻梁挺直，
唇形偏薄，黑发中分低马尾，少量碎发，素颜感，皮肤有真实纹理与细微瑕疵。
正面，平视，85mm 人像镜头，浅景深，纯灰背景，柔和均匀的正面光，
不笑，中性表情，双眼看镜头。写实电影质感，无美颜，无磨皮，无文字。
```

要求：

- 正面、平视、中性表情、眼睛看镜头。
- 纯色背景，无其他人、无文字、无首饰干扰。
- 分辨率 ≥1024，脸部占画面 ≥50%。
- 不要“网红脸、精修、瓷肌、大眼睛”。

### 2. 全身（front full body）

用定脸图作参考，提示词只描述服装与体型，不重复五官：

```
与参考图为同一人，全身正面站立，双臂自然下垂，双脚与肩同宽，
穿深灰棉麻长衫，黑色布鞋，身形清瘦，肩背挺直。
50mm，平视，纯灰背景，均匀柔光，全身入画，头顶与脚下留白。
写实电影质感，真实布料褶皱，无文字，无水印。
```

### 3. 45° 侧面

```
与参考图为同一人，45 度侧面半身，身体朝画面右，脸转向镜头，
同一套服装与发型，纯灰背景，同一柔光。
85mm，平视，写实电影质感，无文字。
```

### 4. 表情组（至少 3 个）

- `expr_neutral`：中性，用于大部分段。
- `expr_pressure`：压住情绪（嘴唇闭紧、下颌微收、眼神不躲）。
- `expr_broken`：崩住（眼眶红、鼻尖红、嘴角发抖但不哭）。

表情图不是表情包。要“抑制中的泄漏”，不要夸张大哭大笑。

### 5. 服装组

每个角色每套造型一张全身：

- `wardrobe_a`：主造型（大多数场次）。
- `wardrobe_b`：变化造型（婚礼、雨夜、受伤后）。
- 只记录变化：外套、发饰、伤痕、血迹。

## 角色卡（写进 bible.md）

| 项 | 内容 |
|---|---|
| 编号 | `CH_SY` |
| 姓名 | 沈砚 |
| 年龄/身份 | 28 / 庶子、账房 |
| 外形关键词 | 清瘦、肩背直、左手腕旧伤 |
| 发型 | 黑发中分低马尾，右侧碎发 |
| 主造型 | 深灰棉麻长衫、黑布鞋、无首饰 |
| 变化造型 | 雨夜湿发、左袖撕裂、手腕红痕 |
| 标志动作 | 说话前先转一下茶杯 |
| 音色 | 低而清，语速慢，气声少 |
| 禁止 | 不要笑出牙、不要现代发型、不要金饰 |

“标志动作”是最便宜的一致性工具。每 2–3 段出现一次，观众会记住这个人。

## 场景板

每个场景至少 3 张，全部**无人物**：

1. `master`：主角度，交代空间与光。
2. `reverse`：反打角度，保证轴线。
3. `detail`：关键道具/桌面/门窗细节。

```
空镜场景板，古代祠堂内，夜，正中供桌，两侧太师椅，右侧木门半开，
窗外雨，桌上长明灯，青砖地，木梁，墙面有多年烟熏痕迹。
35mm，平视，主光为右前方烛光，左后方窗光勾边，光比 6:1。
画面中无人物，无文字，无水印，写实电影质感。
```

场景板的作用是锁空间，不是当背景图直接贴。生成时挂参考，让模型知道门窗位置和光向。

## 道具

关键道具三张：

1. 独立图：纯背景，正面，完整。
2. 手持图：在角色手里，展示比例。
3. 状态图：破损/染血/打开后的样子。

```
道具设定图，一封旧信，宣纸泛黄，边角磨损，火漆封印裂开，
正面平放，纯深灰背景，柔和顶光，微距 100mm，浅景深，
真实纸张纤维，无文字可读，无水印。
```

注意：不要让模型生成可读文字。信件内容用“模糊墨迹”或后期字幕/画外音交代。

## manifest.json

每个资产登记，方便断点续跑与替换：

```json
{
  "characters": [
    {
      "id": "CH_SY",
      "name": "沈砚",
      "version": "v03",
      "face": "characters/CH_SY_face_v03.png",
      "full": "characters/CH_SY_front_v03.png",
      "expressions": ["neutral", "pressure", "broken"],
      "wardrobe": {"a": "characters/CH_SY_wardrobe_a_v03.png"},
      "locked": true
    }
  ],
  "scenes": [
    {"id": "SC_CT", "name": "祠堂", "master": "scenes/SC_CT_master_v01.png", "reverse": "scenes/SC_CT_reverse_v01.png", "locked": true}
  ],
  "props": [
    {"id": "PR_LETTER", "name": "旧信", "image": "props/PR_LETTER_v01.png", "states": ["intact", "torn"]}
  ]
}
```

`locked: true` 表示已确认，后续生成不得替换。要改就升版本，不覆盖。

## 参考图卫生

- 一张图只解决一件事：脸、造型、场景、道具，不要混。
- 参考图里不要有第二个人、文字、水印、强滤镜。
- 光线尽量中性均匀。强侧光参考图会把阴影带进每一段。
- 分辨率不低于 1024×1024；脸部参考不低于 768×768。
- 不要用拼图当参考。模型会把拼图结构学进去。
- 不要同时挂“定妆照”和“另一部戏的剧照”。

## 一致性审核

角色资产做完，做一次三方比对：

1. `face` vs `front`：脸型、发际线、眼距、鼻梁、唇形。
2. `front` vs `wardrobe`：身高比例、肩宽、服装细节。
3. `expr_neutral` vs `expr_broken`：是不是同一个人在同一张脸上做表情。

任何一项明显不像，重做，不要带病进入分镜。

生成后每段再查：

- 脸型与下颌线是否一致。
- 眼距、眼角、双眼皮宽度。
- 发际线与碎发方向。
- 痣、疤、耳形等识别点。
- 服装领口、袖口、扣子、材质。

## 用户提供参考图

先做四项检查：

1. **清晰度**：脸是否够大、够清、无遮挡。
2. **角度**：是否正面或轻微 3/4；大侧脸不适合做定妆。
3. **光线**：是否均匀；强阴影会污染后续。
4. **权利**：是否为用户原创/已授权；是否是在世演员肖像。

不合格时，不要硬用。用文字重建设定图，或请用户补图。

## 肖像与版权

- 不复制在世演员、网红、公众人物的脸。
- 用户提供的真人照片，默认其拥有授权；不确定时提示风险。
- 不用品牌 logo、影视剧照、动漫角色做参考。
- 生成的角色名与设定避免直接对应知名 IP。

## 资产预算

一集 60–90 秒的短剧，建议：

- 主要角色 2–4 个，次要角色 2–3 个（可复用同一演员造型）。
- 场景 3–6 个，每个 3 张板。
- 关键道具 5–12 个。
- 角色图每人 6–10 张，总量控制在 40 张以内。

资产不是越多越好。**一个角色一套脸、一套主造型、三个表情，足够拍一集。**
