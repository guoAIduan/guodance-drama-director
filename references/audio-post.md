# 配音、口型、混音与字幕

短剧的声音不是“配一下”，是**一半的表演**。对白不清楚、口型不对、音乐压人声，画面再好也留不住。

## 正确顺序

**阶段 1–4（生成前）**

1. 台词定稿（字数、气口、说话人）。
2. 每个角色做 2–3 条试音，定音色。
3. 全量 TTS，得到每句的真实时长。
4. 按音频时长回排分镜（必要时拆句/加反应镜）。

**阶段 8–9（生成后）**

5. 生成视频（提示词带对白与语气）。
6. 口型对齐（原生或后期）。
7. 环境声、BGM、音效、混音。
8. 字幕、响度、终检。

试音与时长草稿必须在分镜定稿前完成；最终配音可以在批量生成后重跑，但音色与文本不能变。**不要先拍完再盲配**，画面必须先知道每句话有多长。

## 音色卡

每个角色一张，全剧复用，不跨集换。

| 项 | 示例 |
|---|---|
| 角色 | 沈砚 |
| 年龄感 | 28 |
| 音高 | 中低 |
| 音色 | 清冷、偏薄、不浑厚 |
| 语速 | 慢，约 3.8 字/秒 |
| 气声 | 少，句尾略收 |
| 口音 | 标准普通话，轻微北方腔 |
| 性格 | 克制、不解释 |
| 禁止 | 播音腔、磁性低音炮、油腻气泡音 |

主要角色音色要拉开：不要所有男声都低沉，所有女声都甜。用**音高、语速、气声、咬字**四个维度区分。

不要克隆在世演员或公众人物的声音。

## TTS 标注

不同工具语法不同，但方向一致：

```
[低声] [压着怒] [气息不稳] [语速放慢] [尾音下坠] [停顿0.4s]
```

如果支持 SSML：

```
我知道你当年<break time="500ms"/>做了什么。
```

标注只写可执行的东西。“悲伤地”不如“气息不稳、语速放慢、句尾下坠”。

每句都加“自然说话、不要播音腔、不要念稿感”。TTS 默认会太工整，需要压。

## 语速与时长

中文短剧的可用区间：

| 状态 | 字/秒 | 12 字大约 |
|---|---|---|
| 平静对话 | 4.0–4.5 | 2.7–3.0s |
| 压抑/悲伤 | 3.2–3.8 | 3.2–3.8s |
| 争吵/抢话 | 5.0–5.5 | 2.2–2.4s |
| 喘息/重伤 | 2.5–3.0 | 4.0–4.8s |

分镜时长 = 台词时长 + 0.4–0.8 秒反应/停顿。台词 3 秒，镜头至少 3.6 秒。

台词超过镜头时长 15%，不要加速念，拆句或加镜。

## 口型：三条路线

### A. 原生生成（快，精度一般）

视频模型直接生成说话口型。适合：

- 中景/全景，脸不大；
- 台词短；
- 观众注意力在动作而非嘴形。

提示词写“自然说话状态，口型随台词开合，无夸张念稿感”，不要要求“精确对齐每个字”。

### B. 音频驱动（推荐）

先 TTS 定稿，再用音频驱动口型（对口型模型/工具）。优点：口型准、可改台词。缺点：多一道工序。

流程：

1. 每句单独导出 wav，命名 `EP01_D03_L01.wav`。
2. 记录起止时间，生成 `audio/voice-plan.csv`。
3. 对口型时按句输入，不要整段混音输入。
4. 对齐后回看爆破音（b/p/m）和句尾。

### C. 视频先行（兜底）

已有画面，TTS 后按画面时长微调语速，再做口型对齐。适合补拍/改词。

### 验收标准

- 口型偏差 ≤2 帧（24fps，约 83ms）。
- 每 10 秒允许 ≤1 处明显不同步，且不在特写。
- 句尾不能“嘴停声不停”超过 0.3 秒。
- 特写镜头必须逐句对。

超过标准：重对；不要用“观众看不出来”放行。

## 环境声

每个场景一条底噪，贯穿全场，保证切镜不“真空”：

- 祠堂：雨声、火苗、木梁轻响。
- 办公室：空调、键盘、远处电梯。
- 街道：车流、人声、雨后滴水。
- 武馆：风穿窗、木头、远处狗叫。

底噪音量 -30 至 -24 LUFS，不能盖对白。转场时可以短暂拉低，但不要完全静音，除非是刻意的情绪设计。

## BGM

短剧需要音乐，但音乐是情绪的骨架，不是全程铺满。

- 每集 1–2 个主题动机，固定配器。
- 第一句台词后再进音乐，不要一开场就轰。
- 情绪峰值前 0.5 秒抽掉音乐，只留呼吸/环境，峰值后再进。
- 卡点处音乐不要收尾，留一个未解决的和弦。
- 对白段落音乐降到 -22 至 -18 LUFS， ducking 6–9dB。
- 转场用音乐断点，不要每段重新起。

版权：只用可商用/自制/已授权音乐。不要用热门影视配乐、流行歌片段。

## 音效

三层就够：

1. **动作层**：脚步、衣料、开门、放杯、纸张。
2. **强调层**：耳光、碎裂、刀出鞘、心跳（少用）。
3. **空间层**：混响、远处环境、雨声。

音效不是越多越好。关键动作一个重音，其余留白。打斗不要全程“嘭嘭嘭”，会廉价。

## 混音目标

| 项 | 目标 |
|---|---|
| 整体响度 | -14 LUFS（±1） |
| True Peak | ≤ -1.5 dBTP |
| 对白 | 清晰、居中、-16 至 -14 LUFS 短时 |
| BGM（对白下） | -24 至 -18 LUFS |
| 环境底噪 | -30 至 -24 LUFS |
| 音效峰值 | 不超过 -6 dBFS |

ffmpeg 参考链（对白 + BGM）：

```
[0:a]highpass=f=80,lowpass=f=12000,asplit=2[dlg][key];
[1:a]volume=0.18,highpass=f=120[bg];
[bg][key]sidechaincompress=threshold=0.03:ratio=8:attack=5:release=250[bgduck];
[dlg][bgduck]amix=inputs=2:duration=first:dropout_transition=0,
loudnorm=I=-14:TP=-1.5:LRA=11[aout]
```

对白清理：

```
highpass=f=80,lowpass=f=12000,acompressor=threshold=-18dB:ratio=3:attack=5:release=120
```

先做一版只用对白 + 环境的 `clean` 轨，再做 `broadcast` 混音。两版都交付。

## 字幕

- 每行 ≤12 个汉字，最多 2 行。
- 单条停留 1.5–4 秒，跟台词走。
- 底部安全区：距画面底部 ≥18%，避开平台 UI。
- 不标说话人，短剧观众靠声音和画面分辨。
- 句末不加句号；问号、感叹号可保留。
- 数字用阿拉伯数字；金额、时间写清楚。
- 不把关键词拆到两行。
- 不用花哨字体，黑体/思源黑体，白字 + 20% 黑描边或半透明底。

需要强调的词用花字，但一集不超过 5 处，且不遮挡人脸。

## 交付音频

```
audio/
├── lines/                每句 wav
├── segments/             每段对白 wav（与段等长，供 assemble.ps1 直接读取）
├── voice-plan.csv        角色/台词/起止/时长/音色
├── dialogue.wav          对白干声
├── ambience/             每场底噪
├── bgm/                  主题音乐
├── sfx/                  音效
├── mix_broadcast.wav     混音
└── mix_clean.wav         纯对白
```

`voice-plan.csv` 字段：`line_id,segment_id,speaker,text,start,end,duration,voice,tags,file`。口型对齐与重配都靠它。

`assemble.ps1` 读的是 `audio/segments/D01.wav` 这类段级文件：把该段所有台词行按 `start/end` 铺进一条与段等长的音轨（前面补静音、尾部补静音），不要直接把整集一条 wav 塞进去。

## 声音质检

- [ ] 每句都听得清，没有吞字。
- [ ] 角色音色前后一致。
- [ ] 口型偏差在标准内。
- [ ] 切镜处没有“真空”或底噪突变。
- [ ] BGM 不压对白。
- [ ] 峰值不爆音。
- [ ] 整体响度 -14 LUFS 左右。
- [ ] 字幕与台词一致，没有错别字。
- [ ] 卡点处声音有设计（断、留白、未解决和弦）。
