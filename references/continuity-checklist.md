# 连续性与穿帮预审

连续性不是生成出来再补，是**写分镜时就把变量锁死**。三查：写前查台账、拍前查分镜、出片查素材。

## 一、连续性台账

在 `bible.md` 里维护，逐场更新。缺一项就会在某一段翻车。

| 类别 | 必须记录 |
|---|---|
| 人物 | 本场服装、发型、妆容、伤痕、佩戴物、指甲、鞋 |
| 道具 | 名称、在谁手里、放在哪、状态（完整/破损/染血） |
| 空间 | 平面图、门窗位置、家具朝向、人物站位 |
| 光线 | 时间、主光方向、色温、光比、实用光源 |
| 天气 | 晴/雨/雪/雾，地面干湿，衣物湿度 |
| 情绪 | 入场状态、转折点、出场状态 |
| 信息 | 本场观众知道了什么，人物互相知道什么 |

台账只写“本场变化”，没变的沿用上一场。不要每场重抄一遍。

## 二、空间连续性

- [ ] 上一镜在 A 地，下一镜是否还在 A 地？跳 B 地有没有转场镜（空镜/黑场/叠化/动作匹配）？
- [ ] 人物相对位置是否一致？上镜在画左，下镜不能无理由跳到画右。
- [ ] 门、窗、走廊方向是否统一？上镜门在右，下镜不能跑到左墙。
- [ ] 坐姿/站姿是否延续？坐下、起身、倒下中间有没有动作过程镜？
- [ ] 桌面物件的位置是否一致？杯子、信、刀、手机不能自己移动。
- [ ] 空间大小是否一致？上镜是小书房，下镜不能变成大殿。

**做法**：开拍前画一张俯视平面图，标出摄影机位和人物站位。每镜写“人物在画面左/右、面朝哪”，不要写“两人对峙”。

## 三、动作连续性

- [ ] 上镜人物站着，下镜是否还站着？若坐下/倒下，中间有没有动作过程？
- [ ] 动作方向是否一致？上镜向右拔剑，下镜剑刃不能从左侧出来。
- [ ] 手的位置：上镜双手垂着，下镜不能突然端起茶杯。
- [ ] 动作进度：上镜刀拔到一半，下镜不能已经入鞘。
- [ ] 受力方向：被打左脸，头应该向右偏；下一镜不能捂右脸。
- [ ] 走路方向：上镜从画左走向画右，下镜不能从画右走向画左，除非有转身镜。

**动作接戏三件套**：动作起势镜 → 动作过程（可被遮挡）→ 动作结果镜。切点藏在遮挡、转身、前景经过处。

## 四、视线与轴线

- [ ] 正反打，A 面朝左则 B 面朝右，是否守住轴线？
- [ ] A 看画左，B 是否出现在画左？
- [ ] 两人对视时，眼睛高度是否匹配？不能一个俯拍一个仰拍。
- [ ] 越轴有没有中性镜过渡？
- [ ] 三人以上，主轴线是否明确？
- [ ] 人物看的是“人”还是“某个位置”？视线落点要具体到眼睛、手、门。

生成时的空间锚定句：`A 在画面左侧，身体朝右；B 在画面右侧，身体朝左；两人视线相接，背景门在 B 身后`。

## 五、道具链

- [ ] 上镜手里有剑，下镜剑还在吗？放下/收剑有没有动作镜？
- [ ] 信物（信/玉佩/酒杯/手机）位置是否一致？
- [ ] 伤口/血迹位置：上镜左臂受伤，下镜不能变右臂。
- [ ] 道具状态：信是干的还是湿的？酒杯是满的还是空的？手机屏幕亮不亮？
- [ ] 道具在谁手里：A 递给 B 之后，下一镜不能还在 A 手里。
- [ ] 关键道具是否有“交接动作镜”？没有就补。

**道具链写法**：`道具名 + 持有者 + 位置 + 状态`，每场更新一次。比如 `婚戒：女主右手无名指，第 3 场摘下放桌上，第 5 场仍在桌上`。

## 六、服化与身体状态

- [ ] 服装颜色、材质、领口、袖子是否一致？
- [ ] 发型有没有变？盘发/披发/刘海方向。
- [ ] 妆容有没有跳？口红颜色、眼妆浓淡。
- [ ] 伤痕、淤青、血迹、汗、雨、泥是否连续？
- [ ] 首饰、耳环、手表、戒指是否一致？
- [ ] 鞋是否一致？有没有光脚/换鞋的剧情？

跨集连续的角色，建一个“造型卡”，每集只记录变化。

## 七、时间与光线

- [ ] 上镜白天，下镜不能无转场变夜晚。
- [ ] 烛光/日光方向是否一致？不能上镜阳光从东窗进，下镜变成西晒。
- [ ] 雨景是否连续？上镜下雨，下镜突然天晴要有转场。
- [ ] 室内实用光源是否一致？台灯、壁灯、火盆的位置。
- [ ] 色温是否统一？同一场景不能一会儿暖黄一会儿冷蓝。
- [ ] 光比是否统一？上镜柔光，下镜硬光，要有理由（比如门被推开）。

时间跳跃用三种方式交代：字幕、光线变化、人物造型变化。不要靠观众猜。

## 八、情绪连续性

- [ ] 上镜刚暴怒拍桌，下镜有没有缓冲再切平静？
- [ ] 情绪转折有没有铺垫？不能从微笑瞬切痛哭。
- [ ] 情绪最高点前后有没有节奏落差？前面要压，后面要留白。
- [ ] 人物对同一件事的态度是否自洽？不能上一场不在乎，下一场拼命。
- [ ] 信息差是否连续？人物不能知道观众知道但他不该知道的事。

## 九、跨段接戏：首尾帧三查

同一场戏内，下一段首帧应等于上一段尾帧。接之前查三样：

1. **位置**：人物在画面中的位置、身体朝向。
2. **视线**：看哪里，眼睛高度。
3. **手**：手在做什么，道具在谁手里。

再查两样：**光向**（主光从哪边来）、**景别/焦段**（不要从 85mm 近景直接跳 24mm 全景还要求无缝）。

尾帧不合格时：

- 尾帧有运动模糊 → 往前取 0.2–0.3 秒的清晰帧。
- 尾帧人物在动 → 让上一段结尾多停 0.3 秒，或改用动作切点。
- 尾帧曝光跳 → 先统一两段素材的色调，再交接。

跨场景、跨昼夜、跨情绪段，不用首尾帧，正常硬切。

## 十、成片复检

逐段回看，额外查：

- [ ] 脸是否和定妆图一致（没有“换了个演员”）？
- [ ] 首尾帧衔接处动作是否跳切？
- [ ] 光影是否突变（上镜暖黄下镜冷蓝）？
- [ ] 有没有 AI artifact：多指、穿模、物体悬浮、脸糊、牙齿畸形？
- [ ] 表演是否自然（没有脸僵、念稿、表情过度、眼神空洞）？
- [ ] 对白口型是否和配音对得上？
- [ ] 字幕是否压住人脸或平台 UI？
- [ ] 整体节奏是否拖沓或太赶？
- [ ] 声音是否连续：环境底噪、音乐、对白响度。

## 十一、问题处理矩阵

| 问题 | 处理 |
|---|---|
| 单镜脸崩/手崩 | 换提示词重抽该段，不改分镜 |
| 单镜动作不合理 | 拆动作、简化运镜、延长时长 |
| 跨镜位置跳 | 检查首尾帧；补过渡镜；重写空间锚定 |
| 跨镜光线跳 | 统一画风后缀与光影描述；调色对齐 |
| 道具丢失/错手 | 补交接动作镜；在提示词里写明“右手持 X” |
| 整段情绪不对 | 回阶段 4 改分镜，不要硬抽 |
| 整场空间不成立 | 回平面图重排机位，必要时换场景 |
| 台词时长不够 | 拆句、减字、加反应镜，不要加速念 |

## 十二、连续性高风险清单

这些情况最容易翻车，写分镜时优先规避：

- 三人以上同框对话。
- 人物从坐到站、从站到跪的连续动作。
- 递东西、戴戒指、系扣子、写字等精细手部动作。
- 打斗中的身体接触与武器交换。
- 镜子、玻璃、水面反射。
- 手机屏幕、书信、牌匾等可读文字。
- 雨雪中长时间对话。
- 同一场景内多次换装。
- 儿童、动物、群众演员。
- 快速转身、奔跑、跳下、摔倒。

规避不是删戏，是换拍法：拆镜、换景别、用声音、用反应、用道具特写。
