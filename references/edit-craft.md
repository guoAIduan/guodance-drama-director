# 剪辑与调色

剪辑不是把段按顺序接起来，是**决定观众什么时候知道什么、什么时候喘气**。AI 素材的接缝、节奏和色调，最后都在这里定型。

## 剪辑的三个目标

1. **信息**：观众这一刻知道了什么新东西。
2. **情绪**：观众这一刻该紧、该松、该疼。
3. **节奏**：快慢交替，不让观众疲劳。

每个剪辑点至少服务一个目标。三个都不服务，就是多余的一刀。

## 剪辑点怎么选

| 剪辑点 | 用法 | 注意 |
|---|---|---|
| 动作中 | 手抬起→下一镜手已落下 | 最自然，能藏 AI 接缝 |
| 眨眼 | 说完话眨眼前切 | 适合情绪转场 |
| 呼吸 | 吸气后、呼气前切 | 适合压迫/恐惧 |
| 台词前 | 对方还没开口就切 | 制造预期 |
| 台词后 | 说完停半拍再切 | 留余味 |
| 道具落点 | 杯子落桌、信放下的瞬间切 | 声音和画面同步 |
| 视线转移 | 人物看向某处时切到所看之物 | 引导注意力 |
| 声音先导 | 下一场的声音先进来 | 无缝转场 |

不要在每个镜头“动作做完、停住、再切”。那是最像 AI 拼接的节奏。

## 对白剪辑：J-cut 与 L-cut

- **J-cut**：下一句台词先入，画面还没切。让观众提前进入下一镜。
- **L-cut**：上一句台词延续到下一镜画面。适合反应镜、走位、插入镜。

短剧对话密集，J/L-cut 能让对话“流”起来，不像正反打打乒乓球。

做法：

- A 说完，声音延续 0.3 秒，画面切到 B 的反应。
- B 的话提前 0.2 秒入，画面还在 A 脸上。
- 抢话时，两句话重叠 0.2–0.4 秒。

## 反应镜插入

反应镜是短剧的呼吸：

- 对方说完狠话，切听的人 0.8–1.5 秒。
- 反应镜要有变化：眼神落点、呼吸、手。
- 不要在每句话后都插反应，会碎。
- 峰值前的反应镜可以长一点，让观众等。

## 节奏曲线

一集 60–90 秒，节奏至少三次变化：

```
0–3s    快/准    冷开场，2–3 刀
3–15s   中       立困，对话 2–4 秒
15–35s  渐快     加压，刀变短
35–50s  突变     翻转，先停一拍再爆
50–70s  慢/重    峰值，5–8 秒长镜或极短快切
70–88s  再快     新威胁
88–90s  停       卡点，1.5 秒大特写
```

全程快切会麻木，全程长镜会拖。**峰值前要压，峰值后要留白。**

## 转场

- **硬切**：默认。短剧 90% 用硬切。
- **叠化**：时间流逝、情绪余韵、回忆。一集不超过 2 次。
- **黑场**：段落结束、卡点。不要每场都黑。
- **匹配剪辑**：形状/动作/颜色相似的两个镜头相接。
- **声音转场**：下一场的雨声/电话声提前入。
- **遮挡转场**：人物走过前景、门关上，藏接缝。

不要用花哨转场（翻页、闪白、旋转）。短剧观众要的是信息，不是特效。

## 接缝处理

AI 段与段之间常见三种接缝：

1. **动作跳**：上一段尾帧和下一段首帧姿势不一致。  
   → 用动作中剪辑；中间插 0.3 秒反应/道具特写；或重取尾帧。
2. **光影跳**：色温/亮度突变。  
   → 调色对齐；加 2–4 帧叠化；或重生成。
3. **构图跳**：人物位置突然变。  
   → 用中性镜/空镜过渡；或改景别掩盖。

接缝不要用“闪白”遮。闪白会让观众更注意接缝。

## 调色：先统一，再风格

AI 每段单独生成，色调一定会有差。调色分三步：

### 1. 一级校色（统一）

- 曝光：波形图对齐，人脸中间调一致。
- 白平衡：同一场景色温一致。
- 对比：黑位、白位统一。
- 饱和：整体降 5–15%，避免 AI 的艳。

ffmpeg 简化示例：

```
-vf "eq=contrast=1.05:brightness=-0.01:saturation=0.9,colorbalance=rs=-0.02:bs=0.02"
```

### 2. 二级校色（局部）

- 肤色：单独提亮/降饱和，避免“橘脸”。
- 天空/窗户：压高光，保留细节。
- 暗部：轻微提亮，避免死黑。

### 3. 风格 LUT

全片一个 LUT，强度 30–60%。不要每段换 LUT。

```
-vf "lut3d='looks/warm_brown.cube'"
```

没有 LUT 就用固定参数：低饱和、轻微暖棕、暗部偏青。**关键是全片一致，不是单帧好看。**

## 调色检查

- 同一场景不同段，人脸亮度差不超过 1/3 档。
- 白平衡不跳：白墙/白纸在同一场景应是同一色。
- 肤色不忽冷忽热。
- 黑位不糊成一片。
- 高光不爆（窗户、灯、刀刃）。
- 全片看一遍，不要只看单段。

## 声音与画面的关系

- 声音可以比画面早 0.2–0.5 秒，制造预期。
- 重音落在动作接触帧，不要早于画面。
- 峰值前抽掉 BGM，只留呼吸/环境。
- 卡点处声音不要收干净，留一个尾巴。
- 转场用声音桥，比画面叠化更自然。

## 竖屏剪辑额外规则

- 前 3 秒至少 2–3 刀，别用一个长镜开场。
- 每 5–8 秒给一次景别变化。
- 人脸不要连续 10 秒同一构图。
- 字幕出现时，画面主体不要同时大动。
- 卡点最后一帧要清晰，能当封面。

## 终剪检查

- [ ] 前 3 秒有没有钩子？
- [ ] 每 15 秒有没有新信息？
- [ ] 有没有连续 20 秒没有动作变化？
- [ ] 峰值前有没有压？
- [ ] 峰值后有没有留白？
- [ ] 对白有没有 J/L-cut，还是全程正反打？
- [ ] 接缝有没有明显跳？
- [ ] 色温/肤色有没有跳？
- [ ] 字幕有没有压脸？
- [ ] 最后一帧能不能当封面？
- [ ] 关声音能否看懂 80%？
- [ ] 开声音有没有被 BGM 压住？

## 常见剪辑病

| 病 | 症状 | 药 |
|---|---|---|
| 每镜都停稳再切 | 像 PPT | 在动作中切 |
| 反应镜太多 | 节奏碎 | 每 2–3 句插一次 |
| 长镜无信息 | 拖 | 加插入镜或删 |
| 峰值太早 | 后面泄气 | 把峰值后移，前面加压 |
| 转场太花 | 廉价 | 回到硬切 |
| 调色每段不一样 | 像拼盘 | 一级校色统一 |
| BGM 全程铺满 | 没有呼吸 | 峰值前抽掉 |
| 字幕太长 | 观众读字不看戏 | 每行 ≤12 字 |
