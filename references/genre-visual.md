# 题材视觉系统

先定题材，再定“一剧一貌”。视觉不是滤镜，是**色彩、光线、镜头、材质、运动**五件事的统一。

## 判定流程

1. 读前 3 场 + 人物身份 + 核心冲突，定主题材。
2. 混合题材取主基调，只叠加次题材的**一个**特征（例如“权谋 + 悬疑”只加冷蓝阴影，不要又加雨夜霓虹）。
3. 选定后缀句，逐字固定，全剧不改。
4. 写一张色彩脚本：六拍各是什么色温、饱和度、光比。

## 通用画质后缀

所有题材都挂这一句，放在题材后缀之后：

```
电影级写实质感，真实皮肤纹理与细微瑕疵，自然景深，轻微胶片颗粒，
柔和肤色，真实物理光影，无字幕，无水印
```

不要写“8K 超高清、毛孔可见、极致细节”。这些词会把皮肤推成塑料，布料推成硬壳。

## 色彩脚本（六拍）

每集按六拍排一条色彩曲线，避免全片一个色：

| 拍 | 色温 | 饱和度 | 光比 | 作用 |
|---|---|---|---|---|
| 冷开场 | 冷 | 中低 | 高 | 不安、冲突 |
| 立困 | 中性 | 中 | 中 | 交代 |
| 加压 | 渐冷 | 中低 | 渐高 | 压迫 |
| 翻转 | 突变（暖或冷） | 中 | 高 | 认知翻面 |
| 峰值 | 最暖或最冷 | 低 | 最高 | 情绪定格 |
| 卡点 | 冷 | 低 | 高 | 悬置 |

“突变”必须有物理理由：门开、灯灭、日落、血溅、手机亮。不要凭空调色。

## 混合题材

- 权谋 + 悬疑：暖棕底，阴影加冷蓝，光比 7:1。
- 甜宠 + 悬疑：暖白底，局部冷蓝，浅景深保留。
- 武侠 + 仙侠：冷青底，只加一层体积雾，不加彩色法术。
- 年代 + 家庭：米黄底，光比降到 3:1，肤色更暖。

一次只叠一个次类型特征。叠三个，画面会变成大杂烩。

## 风格锁

选定后写进 `bible.md`：

```
本剧视觉锁：
色彩：低饱和暖棕 + 暗金，饱和度 -20%
光线：右前方烛光主光，左后方窗光轮廓，光比 6:1
镜头：35mm / 50mm / 85mm
质感：16mm 颗粒，轻微暗角，真实皮肤纹理
禁止：8K 塑料感、彩色法术光、现代物品、字幕水印
```

每段提示词逐字复制后缀。中途换风格，观众会以为换了一部剧。

## 不要用导演名当风格词

“参考《一代宗师》调色”“王家卫风格”这类写法有三个问题：不可执行、容易触发版权/模仿争议、模型理解不稳定。改成可执行的描述：

```
低饱和暖棕，窗格投影，大面积暗部，16mm 颗粒，缓慢横移，浅景深
```

这比一个名字更接近你想要的结果。
