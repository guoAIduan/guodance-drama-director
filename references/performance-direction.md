# 表演指导与去 AI 感

AI 人物最假的地方通常不是脸，是**表演像在念稿、表情像表情包、身体像被定住**。表演指导要写成“可观察的行为序列”，不是情绪形容词。

## 核心原则：写行为，不写情绪

| 不要写（AI 感重） | 要写（行为化） |
|---|---|
| 他很愤怒 | 他把茶盏往桌上一顿，茶溅出来也不看，手指点着桌面一下一下 |
| 她很伤心 | 她别过脸去假装看窗外，喉咙动了一下，手攥紧袖口又松开 |
| 他很震惊 | 他举着酒杯停在半空，没喝也没放下，眼睛眨了两下 |
| 她冷笑 | 她扯了下嘴角没出声，端起茶吹了吹，吹了很久 |
| 他紧张 | 他把腰带扣解开又系上，系了两次，话在嘴里顿了一下才说出口 |
| 她心虚 | 她语速突然变快，解释得特别详细，手一直整理并不乱的桌布 |
| 他得意 | 他假装不在意，嘴角压不住往上走，故意把话题岔开 |
| 她失望 | 她愣了两秒，点点头，说“行吧”，转身去洗碗 |

## 导演指令：目标、障碍、战术

每场戏先写三行，给演员（也给模型）一个可执行的心理动作：

- **目标**：这场戏她想要什么？必须具体到“让他签下这份协议”，不是“想被理解”。
- **障碍**：谁或什么在挡？对方的权力、自己的秘密、时间。
- **战术**：她用什么手段？示弱、激将、交换、沉默、威胁、转移话题。

台词是战术，不是情绪。人物说“你吃饭了吗”，可能是在试探、拖延、求和或下逐客令。**潜台词写进分镜表的“潜台词”列，不要写进画面描述**。

## 节拍：起、压、破、收

一场 30–60 秒的戏，表演至少有一个四拍变化：

1. **起**：人物带着一个状态进入（压着火、假装没事）。
2. **压**：对方的动作/台词让状态被压住，人物试图维持。
3. **破**：维持失败，泄漏出一个真实反应（手抖、声音变、视线躲）。
4. **收**：人物重新组装自己，回到一个“新的假面”。

不要一上来就演峰值。峰值前面没有压，观众不会疼。

## 听戏：60% 的表演在听

反应镜最容易假：AI 会让角色点头、微笑、皱眉，像在开会。真实听戏是**有变化**：

- 眼神落点变了：从对方眼睛移到对方的手，再移回。
- 呼吸变了：吸一口气停住，或者慢慢吐出来。
- 手有事做：捏杯沿、搓纸角、按住桌面的木纹。
- 身体重心变了：往后靠半寸，或者前倾。
- 该有反应时没反应：听到坏消息先愣住，两秒后才眨眼。

反应镜的提示词不要写“他听着”，要写“他原本在擦杯子，听到‘亲子鉴定’四个字，手停在杯口，布掉在桌上，他没去捡”。

## 微表情的时间学

一个真实微表情不是一瞬间的“表情包”，而是三段：

1. **触发**（0.2 秒）：眼角/鼻翼/嘴唇先动。
2. **抑制**（0.5 秒）：人物意识到不该露，压回去。
3. **泄漏**（0.8–1.2 秒）：压不住的地方漏出来，通常在手、呼吸或视线。

提示词可以写成：`听到这句话，他先眨了一下眼，随即垂下视线去端茶，端起来又放下，茶一口没喝`。

不要写“表情复杂”。模型会把“复杂”翻译成面瘫。

## 身体：重心、呼吸、手

AI 人物最常见的“假”是站桩：脚不动、肩不晃、只有嘴在动。每镜至少给身体一个任务：

- **重心**：重心在左腿还是右腿？有没有换脚？
- **呼吸**：胸口/肩膀有没有起伏？长台词前有没有吸气？
- **手**：手在干什么？垂着、撑着、攥着、整理、递、挡。
- **肩背**：放松还是绷紧？有没有驼背、后仰、侧身？
- **距离**：两人之间是靠近、后退，还是隔着桌子。

手是最好的表演工具。给手一个“无意义但有生活感”的任务：擦杯子、捻佛珠、转打火机、抠桌缝、理袖口、把筷子摆正。

## 反应镜的五种用法

1. **确认**：对方说完，他眨一下眼，表示听懂了。
2. **否认**：他摇头，但手在发抖。
3. **计算**：他视线下移，手指在桌面轻点，像在算账。
4. **崩塌**：他张了张嘴，没发出声，慢慢坐下。
5. **决定**：他停止小动作，抬眼，身体前倾。

每场戏至少有一个“决定”反应镜。观众要看见人物从被动变主动的那一刻。

## 台词：气口与悬念

真人说话是碎的。不要让人物一口气把台词念完。

### 长句拆段

超过 15 字拆成 2–3 段，中间插动作或反应。

错误：`他说：“我知道你当年做了什么，你以为藏得住吗？”`

正确：

- 镜 A：他低头擦杯子，“我知道你当年……”（杯沿在手里转了半圈）
- 镜 B：抬眼，“做了什么。”
- 镜 C：对方攥紧筷子，他补一句，“你以为藏得住？”

### 气口的写法

- 每 3–8 字留一个气口，但气口不是空白，是人物在做小动作。
- 写法：`（停顿 0.5 秒，他别过脸去看窗外）`
- 常见气口动作：吞口水、视线移开、手指敲桌面、端杯吹一下、整理袖口、叹口气。
- 不要在气口写“沉默”。写“他在做什么”。

### 悬念：话留半句

- **被打断**：“我其实一直——”“够了。”
- **自己吞回去**：“你以为我想这样？算了，当我没说。”
- **转移视线**：“那天晚上，他……”（看向门口，不说了）

每段戏至少有一处话留半句。这就是观众往下看的理由。

### 接话与抢话

- A 没说完 B 就接：“你不用解释，我——”“我不是要解释。”
- 答非所问：“你去哪？”“饭在锅里。”
- 话赶话越说越快，最后一句突然压低。
- 允许重复对方的话，像在确认，也像在拖延。

### 动作戏里的台词

打戏里人物不说话，呼吸和短句跟动作绑定：

- 发力时从牙缝挤字：“就这？”
- 挨打后咬牙：“……你完了。”
- 打完只剩喘息，不说话，胸口起伏。

不要一边流畅打一边冷静念台词，那是 AI 感的重灾区。

## 不同情绪的表演处方

- **暴怒**：不大喊。声音压低、语速变慢，手控制不住地做一件无意义的事（叠衣服、擦桌子、摆正筷子）。
- **悲伤**：不立刻哭。先笑一下，笑完才反应过来不该笑，眼眶红了但忍住，转身找事做。
- **恐惧**：不瞪眼。整个人僵住、呼吸变浅、后退半步、手抓住身边的东西。
- **心虚**：话变多、语速变快、不敢直视、解释得特别详细、越描越黑。
- **得意**：不大笑。忍着、假装不在意、嘴角压不住、故意转移话题。
- **失望**：不叹气。愣两秒，点头，说“行吧”，转身做事。
- **羞辱**：不当场爆发。先看一圈周围人的脸，再把眼泪咽回去，动作变得特别轻。
- **决绝**：不喊口号。把一个物件放下，动作很稳，然后不看对方一眼地走。
- **爱意**：不说“我爱你”。记住对方不吃香菜，把碗换过去，假装顺手。

## 群戏与打戏

群戏：

- 只给 2 个人清晰正脸，其余用背影、虚焦、画外声。
- 每人一个“权力位置”：坐着的、站着的、靠门的、被围在中间的。
- 反应镜优先给“最不该有反应的人”。

打戏：

- 打之前先给一个“不想打”的理由：护住身后的人、看地上的孩子、退半步。
- 每一击有因果：攻击 → 防守/受力 → 结果（位移、破碎、喘息）。
- 打的过程中给一次“停顿”：两人分开、喘气、对视。全程快切会麻木。
- 打完给一个生活动作：捡起掉落的发簪、擦嘴角的血、把倒下的椅子扶起来。

## 禁用词表（AI 模板神态）

这些词一出现，表演大概率变假，一律删掉改写：

```
心头一震、目光一沉、瞳孔一缩、嘴角勾起、嘴角上扬、眉头微蹙、
眼神复杂、意味深长、若有所思、淡然一笑、冷冷一笑、噙着泪、
咬着唇、攥紧拳头、怒目而视、莞尔、颔首、冷哼一声、
瞳孔地震、眼神拉丝、空气凝固、气场全开、压迫感十足、
眼中闪过一丝、脸上写满、情绪崩溃、歇斯底里
```

“眼中闪过一丝……”是最典型的偷懒写法：模型会给你一个没有焦点的眼神。改成手、呼吸、视线落点。

## AI 表演十二宗罪

1. 说话时身体完全不动。
2. 表情比台词早到或晚到半拍。
3. 每句话都点头，像在开会。
4. 眼神看镜头而不是看对手。
5. 哭和笑都从嘴开始，眼睛没动。
6. 手悬在半空，没有落点。
7. 动作太整齐、太用力，像摆拍。
8. 走路像滑行，脚没有抓地。
9. 说完台词立刻回到中性脸。
10. 两个人说话像打乒乓球，没有抢话和重叠。
11. 情绪只有两档：零和满。
12. 峰值时大喊大叫，前面没有压。

生成后看到任意三条，判表演不通过。

## 把表演翻译成提示词

一个可用的表演句包含四样：

```
[身体在做什么] + [手在做什么] + [视线去哪] + [台词怎么变]
```

例子：

```
他原本在擦杯子，听到“鉴定”两个字，手停在杯口，布掉在桌上没捡，
视线从对方脸上移到门口，声音压低半度：“你再说一遍。”
```

不要写“他震惊地问”。要写震惊导致的动作失灵。

## 表演质检

回看时逐条问：

- 这句台词的情绪，身体跟上了吗？
- 听的人有变化吗？
- 有没有一个动作是“只有这个人物会做”的？
- 峰值前有没有压？
- 说完最后一句，人物有没有“收”的动作？
- 眼睛有没有焦点？
- 手有没有落点？
- 呼吸看得见吗？

任何一项明显缺失，按 `retry-playbook.md` 的“表演假”类型重抽。
