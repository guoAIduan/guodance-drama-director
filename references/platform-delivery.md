# 平台交付与合规

成片不是导出就完事。平台压缩、UI 遮挡、AI 标识、版权与内容红线，任何一项没处理，都可能导致限流或下架。

## 一、通用技术规格

| 项 | 建议 |
|---|---|
| 画幅 | 9:16（1080×1920） |
| 帧率 | 30fps，全片统一 |
| 编码 | H.264 High Profile，yuv420p |
| 码率 | 8–12 Mbps（1080p 竖屏） |
| 音频 | AAC 192kbps，48kHz，立体声 |
| 响度 | -14 LUFS，True Peak ≤ -1.5 dBTP |
| 容器 | MP4，`+faststart` |
| 时长 | 60–90 秒（按平台/剧本调整） |

导出命令：

```
ffmpeg -i master.mov ^
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2,setsar=1,fps=30" ^
  -c:v libx264 -profile:v high -preset slow -crf 20 -maxrate 12M -bufsize 24M ^
  -pix_fmt yuv420p -c:a aac -b:a 192k -ar 48000 -movflags +faststart ^
  EP01_broadcast.mp4
```

不同平台会二次压缩。给平台的文件宁可略高码率，不要低码率再被压一次。

## 二、安全区

竖屏画面分三块：

```
┌────────────────────┐
│ 顶部 10–12%         │  状态栏/平台标题，不放关键信息
├────────────────────┤
│                    │
│   核心区 60%        │  人脸、动作、关键道具
│                    │
├────────────────────┤
│ 底部 18%            │  字幕、按钮、进度条
└────────────────────┘
       右侧 12%        点赞/评论/分享按钮
```

规则：

- 人脸中心放在画面上 1/3，不要顶到状态栏。
- 字幕放在底部 18% 以上，不要压嘴。
- 关键证据/道具不要放在右下角，会被按钮挡。
- 前 3 秒不要放需要读的文字。
- 封面同理：主体居中偏上。

## 三、封面与标题

封面：

- 用情绪最高点或反转瞬间的帧，不用空镜。
- 人物眼神看镜头或看向画面内的冲突点。
- 画面内不要自带大字；标题用平台工具叠加。
- 同时导出 9:16 和 3:4 两个版本（主页网格常用 3:4）。

标题：

- ≤12 字，前 6 字放冲突或身份。
- 用具体信息，不用“震惊”“必看”。
- 不剧透反转结果，只给问题。

示例：

- “她给婆婆递了份亲子鉴定”
- “离婚当天，他叫了我一声姐”
- “全公司都以为她是保洁”

文案：

- 1–2 行，补足标题没说完的信息。
- 结尾留一个问题，引导评论。
- 3–5 个标签：题材 + 人设 + 情绪，不要堆无关热词。

## 四、AI 生成内容标识

按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）及平台规则，AI 生成内容需要**显式标识 + 隐式标识**：

- **显式**：画面角标“AI 生成”或片头/片尾说明，位置明显、可读、贯穿或至少覆盖开头/结尾。
- **隐式**：文件元数据写入生成信息，如 `AIGC`、`AI-generated`、生成工具/时间。
- 发布时按平台要求勾选“内容由 AI 生成”等声明。

ffmpeg 写元数据示例：

```
-metadata comment="AI-generated content; produced with Seedance pipeline"
-metadata encoding_tool="guodance-drama-director"
```

显式角标不要遮挡人脸和字幕，不要做成几乎看不见的小字。平台规则会更新，发布前核对当期要求。

## 五、内容红线

以下内容不要碰，或必须改写：

- 色情、性暗示、擦边暴露。
- 血腥、虐杀、详细自残/自杀过程。
- 未成年人恋爱、性化、婚育。
- 赌博、诈骗、制毒吸毒的具体方法。
- 医疗功效承诺、偏方治病。
- 封建迷信作为现实指导。
- 群体歧视、地域黑、性别仇恨。
- 炫富、拜金、美化复仇私刑。
- 真实人物/事件造谣、影射。
- 未经授权的品牌、影视、游戏 IP。

处理原则：**保留戏剧冲突，删掉可模仿的细节和明确指向**。用遮挡、画外、结果代替过程。

## 六、版权

- 音乐：自制/购买/平台曲库，保留授权记录。
- 字体：商用可用的黑体，不用系统默认未授权字体。
- 参考图：用户原创或已授权；不用影视剧照、动漫角色、在世演员肖像。
- 剧本：不直接复制受版权保护的台词、桥段、人物关系。
- AI 模型：遵守所用工具的商业使用条款。

## 七、交付清单

```
delivery/
├── EP01_broadcast.mp4     上线版（对白+BGM+环境+字幕可选）
├── EP01_clean.mp4         纯对白版
├── EP01.srt               字幕
├── EP01_cover_9x16.jpg    竖屏封面
├── EP01_cover_3x4.jpg     主页封面
├── EP01.wav               混音母版
├── EP01_dialogue.wav      对白干声
└── publish.md             标题/文案/标签/标识/合规备注
```

`publish.md` 至少写：

- 3 个标题备选；
- 2 版文案；
- 5 个标签；
- 封面帧时间码；
- AI 标识方式；
- 合规风险与处理；
- 需要用户确认的点。

## 八、发布前终检

- [ ] 手机竖屏完整看一遍。
- [ ] 前 3 秒有钩子，没有被 UI 挡。
- [ ] 字幕在安全区，没有错别字。
- [ ] 响度稳定，没有爆音。
- [ ] 封面能看清脸和冲突。
- [ ] 标题 ≤12 字，不剧透。
- [ ] AI 标识已加，元数据已写。
- [ ] 音乐/字体/参考图授权可查。
- [ ] 没有平台红线内容。
- [ ] 文件命名规范，版本号正确。

## 九、A/B 版本

同一集可以出两个版本测试：

- **钩子 A**：以冲突台词开场。
- **钩子 B**：以反常动作开场。

只改前 3 秒和封面，其余不动。一次只测一个变量，否则不知道哪个起作用。
