# Seedance 提示词工程

提示词不是文学描述，是**给模型的施工图**。目标是让 8 秒里只发生一件清楚的事，并且脸、光、动作、口型都可控。

## 第一步：探测模型能力

不同入口的 Seedance 能力不一样，排段前先确认，把结果写进项目根目录 `model-profile.md`：

| 能力 | 要确认什么 | 影响 |
|---|---|---|
| 单次时长 | 5s / 8s / 10s / 12s 档位 | 段长与切段 |
| 画幅 | 9:16 / 16:9 / 1:1 | 构图与交付 |
| 参考图 | 最多几张，是否支持多角色 | 同框人数 |
| 首尾帧 | 是否支持首帧、尾帧或两者 | 跨段接戏 |
| 原生音频 | 是否生成对白/音效 | 是否后期配音 |
| 负面词 | 是否支持独立负面提示 | 负面词写法 |
| 随机种子 | 是否可固定 | 重抽与复现 |
| 多镜叙事 | 单次是否支持镜头切换 | 段内镜头数 |

没有探测就写“15 秒一镜到底”，是在赌模型。**默认按 8 秒一段排，探测后再调整。**

## 生成单位：一段只做一件事

- 一段 = 一次调用 = 4–12 秒（默认 8 秒）。
- 一段内 1–3 镜，必须同地点、同光线、同情绪方向。
- 一段只允许一个情绪转向：压住 → 泄漏，或平静 → 决定。
- 同框正脸 ≤2 人。
- 一段只写一个主动作链，不要“边走过来边脱外套边说话边坐下”。

需要更多内容，切段，不要拉长。

## 提示词七块结构

按这个顺序写，模型对前 1/3 的权重最高：

```
【镜头】景别 + 焦段 + 机位高度 + 运镜（一镜一个运动）
【主体】@角色A（与参考图一致，穿本场服装）+ 动作 + 表演
【环境】地点 + 时间 + 天气 + 关键陈设
【光线】主光方向 + 色温 + 光比 + 实用光源
【风格】题材后缀（逐字复制，全片不改）
【对白】谁 + 原话 + 语气 + 气口 + 口型要求
【负面】通用 + 表演 + 题材 + 动作
```

如果模型对风格句不敏感，可以把【风格】提前到第二块，但**全片必须统一位置**，不要一会儿前一会儿后。

## 参考图策略

- 一个角色最多挂 **1 张脸部参考 + 1 张全身造型参考**。挂太多会互相稀释。
- 场景挂 1 张场景板（无人物），不要挂带人的剧照。
- 道具挂 1 张独立道具图，必要时加 1 张手持图。
- 参考图必须是同一版造型。换装就换一套参考，不要混用。
- 提示词只写 `与参考图为同一人`，**不写长相**。写“柳叶眉、丹凤眼、白衣”会覆盖参考图，导致漂移。
- 多角色写法：`@沈砚 在画面左侧，@沈母 在画面右侧，两人均与各自参考图一致`。

参考图编号规则见 `asset-bible.md`。提示词里只写编号，不写文件名长串。

## 首帧与运动描述

图生视频的首帧已经决定了长相、服装、光线、构图。提示词**不要重复描述首帧**，要描述“从首帧开始怎么动”：

```
从首帧开始，人物保持坐姿，右手把茶杯放回桌面，视线从门口移回对方脸上，
肩膀先松下来，再开口说话。
```

首尾帧模式则描述“中间路径”：

```
人物从低头擦杯子的姿势，缓慢抬眼看向对面，身体前倾半寸，
手停在杯口不动；结尾停在抬眼直视对方的瞬间。
```

不要把首帧和尾帧各描述一遍，模型会在中间乱跳。

## 多角色：用空间锚定，不用“对峙”

“两人对峙”会让模型自由发挥，位置、视线、朝向每次都不一样。改成：

```
@A 在画面左侧，身体朝右，距桌面一拳；@B 在画面右侧，身体朝左，
背对窗户；两人视线相接，A 的手在桌面，B 的手在膝上。
```

三人以上：

```
@A 在前景左侧，清晰；@B 在中景右侧，清晰；@C 在背景门口，
背光剪影，不露正脸。
```

## 对白写法

- 一段最多 2 句，每句目标 ≤12 字，硬上限 18 字。
- 用中文引号写原话，标点就是节奏。
- 语气用可执行词：低声、压着、气息不稳、语速慢、尾音下坠、没抬头。
- 气口写在台词里：`“我知道你当年……（停顿，手指在杯沿转了半圈）做了什么。”`
- 结尾加：`自然说话状态，口型随台词变化，无念稿感`。
- 无台词写：`本段无对白，只有呼吸和动作声`。

不要写“他愤怒地说”。写“他压着声音，语速比平时慢半拍”。

如果模型原生音频不支持中文，或口型很差：

- 视频阶段只要求“说话状态、口型自然开合”，不要求精确对齐；
- 后期用 TTS + 口型对齐（见 `audio-post.md`）；
- 提示词里不要写“精确对上台词”，模型做不到，反而会嘴部抽搐。

## 动作写法：因果链，不是动作名词

错误：`他打了一拳，对方飞出去。`

正确：

```
0.0–0.8s：他右脚后撤半步，重心下沉，右拳从腰侧起。
0.8–1.2s：拳到对方面门前，对方左臂抬起格挡，小臂相撞。
1.2–2.0s：对方被推力带得后退两步，撞翻条案，茶盏落地碎裂。
```

五拍：**起势 → 发力 → 接触 → 受力 → 结果**。每拍写清身体部位、方向、速度。

不要在一段里写三套招式。一段一套，打完切段。

动作词要带物理：重量、惯性、反作用力、重心、摩擦、碎片、尘土、回弹。不要只写“快、狠、帅”。

## 镜头语言词表（中英都可，选一种用）

| 中文 | 英文 | 提示词写法 |
|---|---|---|
| 大远景 | extreme wide shot | 人物极小，环境占 80% |
| 远景 | wide shot | 全身 + 大量环境 |
| 全景 | full shot | 全身入画，头顶留白 |
| 中景 | medium shot | 腰部以上 |
| 中近景 | medium close-up | 胸部以上 |
| 近景 | close-up | 肩部以上 |
| 特写 | tight close-up | 脸部占画面 60% |
| 大特写 | extreme close-up | 只拍眼睛/手/道具 |
| 固定 | static camera | 机位不动 |
| 慢推 | slow push in | 2 秒从中景到近景 |
| 拉出 | pull out | 从人脸到全景 |
| 横移 | truck left/right | 平行移动 |
| 跟拍 | tracking shot | 保持人物在画面 1/3 |
| 手持 | handheld | 轻微呼吸感，不晃 |
| 环绕 | orbit | 半圈，不超过 180° |
| 平视 | eye level | 默认 |
| 低角度 | low angle | 压迫 |
| 高角度 | high angle | 脆弱 |
| 俯拍 | overhead | 命运感 |
| 三分法 | rule of thirds | 人物在 1/3 线 |
| 框架构图 | frame within frame | 门/窗框住人物 |
| 前景遮挡 | foreground occlusion | 隔肩/树叶/柱子 |

一镜只选一个运镜。不要“推拉摇移跟”全上。

## 光影写法

不要只写“暖光”“电影感”。写四样：

```
主光：右前方 45°，3200K 烛光，柔光
辅光：左后方 5600K 窗光，弱，只勾轮廓
光比：4:1，暗部保留细节
实用光源：桌上油灯，画面内可见，火苗轻微跳动
```

常见组合：

- 权谋：侧逆光 + 窗格投影 + 大面积暗部，光比 6:1。
- 甜宠：窗边自然光 + 柔光漫射，光比 2:1，肤色暖。
- 悬疑：单光源硬光 + 冷蓝环境，光比 8:1，阴影死黑但有轮廓。
- 武侠：逆光轮廓 + 雾气 + 冷青天光，光比 5:1。
- 仙侠：丁达尔体积光 + 自发光 + 雾气，光比 3:1，高光柔。

光比是专业词，模型不一定懂，但配合“暗部细节/硬阴影/柔和过渡”会稳定很多。

## 风格后缀

从 `genre-visual.md` 复制，逐字不改。不要每段重新造句。

通用后缀建议：

```
电影级写实质感，真实皮肤纹理与细微瑕疵，自然景深，轻微胶片颗粒，
柔和肤色，真实物理光影，无字幕，无水印
```

**不要写“8K 超高清”**。它会把皮肤、布料、毛发推成塑料感，也会让画面过度锐化。需要清晰度就写“4K、细节清晰”，不要堆分辨率。

## 负面词库

通用（每段都挂）：

```
多余手指，缺失手指，融合手指，手部畸形，面部扭曲，左右脸不对称，
牙齿畸形，眼部畸形，穿模，物体悬浮，肢体穿插，画面闪烁，
风格突变，光影跳变，字幕，水印，logo，文字，分屏，画中画
```

表演（每段都挂）：

```
表情僵硬，念稿感，夸张表演，面部 AI 感，眼神空洞，口型不符，
说话时身体不动，点头机器，假笑，面瘫，情绪突变
```

古装/年代追加：

```
眼镜，手表，手机，电线，空调，塑料，拉链，现代建筑，现代妆容
```

动作追加：

```
慢动作僵硬，关节反折，动作不自然，武器穿模，AI 隐性降速，
动作插值柔化，空中旋转减速，站桩蓄力，招式间长停顿，结尾摆 pose，
敌人呆站排队，扎堆穿模，轮流上前挨打，无受力浮空，打击绵软，
敌人无身体形变，撞击无碎片，主角原地只做上半身攻击
```

不要把所有负面词无脑堆进去。负面词太多会挤压正面描述。**通用 + 表演必挂，其余按场景选 5–10 个。**

## 长度与信息优先级

- 8 秒段：180–320 个汉字。
- 10–12 秒段：260–380 个汉字。
- 超过 380 字，模型会丢中间信息。拆段。
- 优先级：镜头与主体动作 > 表演 > 对白 > 光线 > 风格 > 负面。
- 一段只保留一个“必须发生”的动作。其他都是修饰。

## 完整示例一：文戏（8 秒，两镜）

```
【镜头】中近景，50mm，平视，固定机位；1.5 秒后硬切近景，85mm。
【主体】@沈砚 在画面左侧，与参考图一致，穿深灰长衫；他原本在擦茶杯，
听到“鉴定”两个字，手停在杯口，布掉在桌上没捡，视线从对方脸上移到门口。
【环境】祠堂内，夜，供桌、长明灯、两把太师椅；窗外有雨声。
【光线】主光为右前方 3200K 烛光，柔；左后方 5600K 窗光勾轮廓；光比 4:1，
暗部保留木纹细节；长明灯火苗轻微跳动。
【风格】电影级写实质感，低饱和暖棕暗金色调，窗格投影与烛火侧光，
大面积暗部，16mm 胶片颗粒，真实物理光影，无字幕，无水印。
【对白】沈砚压着声音，语速比平时慢半拍：“你再说一遍。”
（停顿 0.4 秒，他抬眼看对方）口型自然，无念稿感。
【负面】多余手指，面部扭曲，表情僵硬，念稿感，眼神空洞，字幕，水印，
现代物品，光影跳变，画面闪烁。
```

## 完整示例二：情绪峰值（8 秒，一镜）

```
【镜头】近景，85mm，略低机位，缓慢推近，2 秒完成。
【主体】@林晚 在画面中央偏右，与参考图一致，穿米白毛衣；她一直低着头
把桌上的药盒摆正，听到“孩子归他”后，手停住，药盒倒下，她没有扶，
先笑了一下，笑到一半停住，喉咙动了一下，抬眼看对方，眼眶红但没掉泪。
【环境】律师事务所会议室，下午，百叶窗、长桌、两杯没动的水。
【光线】右侧窗光透过百叶窗，脸上有细条阴影；左侧白墙反光补暗部；

【对白】林晚很轻地说：“行。” 停半秒，补一句：“都行。”

【负面】表情僵硬，夸张哭泣，念稿感，眼神空洞，假笑，面部 AI 感，
```

## 完整示例三：打戏（10 秒，三镜）

```
【镜头】全景 24mm 略低机位，固定；0–3.2 秒。随后硬切中景 35mm 跟拍，
3.2–6.4 秒；最后近景 85mm 固定，6.4–10 秒。
【主体】@沈砚 在画面左侧，深色飞鱼服，右手握刀未出鞘；@刺客 在右侧，
黑衣，短刀反握。0–1 秒沈砚右脚后撤，重心下沉；1–2 秒刺客前刺，
沈砚侧身，刀鞘格开短刀；2–3.2 秒沈砚顺势推鞘，刺客后退撞翻木架。
3.2–5 秒刺客稳住，二次扑上；5–6.4 秒沈砚转身，刀鞘击中刺客手腕，
短刀脱手插入地面。6.4–10 秒沈砚停手，胸口起伏，低头看了一眼地上的短刀，
没有补刀。
【环境】废弃武馆，夜，木人桩、翻倒的兵器架、地面积灰；窗外冷月光。
【光线】左后方 5600K 月光逆光，勾人物轮廓；右前方 3200K 破灯笼暖光，
照局部；光比 6:1；打斗扬尘在光束里可见。
【风格】电影级写实武侠风，冷青灰色调，逆光轮廓与灰尘颗粒，
低饱和，真实物理碰撞，轻微胶片颗粒，无字幕，无水印。
【对白】无对白，只有呼吸、脚步、木架碎裂声；结尾沈砚喘息，压低声音：
“谁让你来的。” 口型自然。
【负面】慢动作僵硬，关节反折，武器穿模，敌人呆站排队，轮流上前挨打，
无受力浮空，打击绵软，撞击无碎片，结尾摆 pose，字幕，水印，光影跳变。
```

## 提示词自检 10 条

1. 这一段是否只有一个地点、一个时间、一个光线状态？
2. 同框正脸是否 ≤2？
3. 是否只有一个主动作链？
4. 是否只有一个情绪转向？
5. 台词是否 ≤2 句、每句 ≤12 字（最长 18）？
6. 是否写了“与参考图为同一人”，且没有复述长相？
7. 是否写清了主光方向、色温、光比？
8. 是否只用一个运镜？
9. 负面词是否覆盖表演与手部？
10. 字数是否在 180–320（8 秒段）？

任何一条不过，先改提示词，不要靠重抽碰运气。

## 常见错误对照

| 错误写法 | 问题 | 改法 |
|---|---|---|
| 她非常悲伤地看着他 | 情绪词，模型给面瘫 | 她别过脸，手攥紧袖口，喉咙动了一下 |
| 两人激烈对峙 | 空间不明，位置乱跳 | A 在左朝右，B 在右朝左，距离一臂 |
| 镜头推拉摇移 | 复合运镜，画面崩 | 只保留慢推 |
| 8K 超清，毛孔可见 | 塑料感、过度锐化 | 4K，真实皮肤纹理与细微瑕疵 |
| 他愤怒地大喊 | 表演单一 | 他压低声音，语速变慢，手指点桌 |
| 一镜 20 秒 | 超模型上限 | 拆成 3 段，首尾帧接 |
| 三个角色同框对话 | 脸必崩 | 两人同框，第三人过肩/画外 |
| 写“参考《一代宗师》” | 风格不可执行，版权风险 | 写色调、光比、颗粒、焦段 |
