# 段级模板（一次生成 = 4–12 秒）

段是生成单位，不是叙事单位。一个 90 秒的单集大约 10–15 段，不是 1 段，也不是 40 段。

## 何时合并，何时拆

**合并成一段**，必须同时满足：

- 同一地点、同一时间、同一光线方向；
- 动作连续，或能用遮挡藏切点；
- 同框正脸 ≤2 人；
- 只有一个情绪转向；
- 总时长 ≤ 模型单次上限（默认 8 秒，最多 12 秒）。

**必须拆段**：

- 换地点、换昼夜、换天气；
- 情绪从“压”跳到“爆”，或从“悲”跳到“狠”；
- 人物组合变化（A+B → A+C）；
- 动作从对峙进入身体接触；
- 台词超过 2 句或超过 24 字。

拆段不是碎片化。拆完仍然要保证段与段之间的动作、视线、光线接得上。

## 模板 A：文戏（2 镜，8 秒）

```
【段号】D03
【场次】S02 祠堂夜
【时长】8 秒（0.0–8.0）
【镜数】2
【画幅】9:16
【参考图】CH_SY_v03（沈砚脸）、CH_SY_full_v02（沈砚造型）、SC_CT_v01（祠堂）

【镜头 1｜0.0–4.0】
景别/焦段：中近景，50mm，平视，固定
构图：三分法，沈砚在画面左侧 1/3，视线向右留白
画面：沈砚坐在太师椅上擦茶杯，听到“鉴定”两个字，手停在杯口。
表演：布掉在桌上没捡；视线从对方脸上移到门口；肩膀先绷紧再松下来。
对白：沈母（画外）：“鉴定结果出来了。”
光线：右前方烛光 3200K，左后方窗光 5600K 勾轮廓，光比 4:1。
环境反馈：长明灯火苗晃了一下，窗外雨声持续。

【镜头 2｜4.0–8.0】硬切
景别/焦段：近景，85mm，略低机位，固定
构图：居中偏右，背景门框形成框架
画面：沈砚抬眼，看向沈母；手仍停在杯口。
表演：喉咙动了一下；开口前停半秒；说完视线不躲。
对白：沈砚压着声音：“你再说一遍。”
光线：同一主光，脸部半明半暗，眼神光可见。
环境反馈：雨声压低，只剩火苗轻响。

【段尾帧】沈砚抬眼直视，手停在杯口，供下一段首帧使用。
【负面】表情僵硬，念稿感，眼神空洞，多余手指，字幕，水印，光影跳变。
```

```
【画幅】9:16

【镜头｜0.0–8.0】
景别/焦段：近景，85mm，平视，2 秒缓慢推近

对白：林晚很轻：“行。”（停 0.5 秒）“都行。”
光线：右侧百叶窗 5000K，细条阴影落在脸上；左侧白墙反光补暗部；光比 3:1。

【段尾帧】林晚抬眼，眼眶红，嘴角还挂着没收回的笑。
【负面】夸张哭泣，表情僵硬，念稿感，假笑，眼神空洞，字幕，水印。
```

## 模板 C：打戏（3 镜，10 秒）

```
【段号】D07
【场次】S03 武馆夜
【时长】10 秒（0.0–10.0）
【镜数】3
【画幅】9:16
【参考图】CH_SY_v03、CH_SY_action_v01、CH_CI_v01、SC_WG_v02

【镜头 1｜0.0–3.2】全景，24mm，略低机位，固定
画面：沈砚在左，刺客在右，相距两步。刺客短刀反握前刺；沈砚侧身，
刀鞘格开；刺客被推力带得后退，撞翻木架。
表演：沈砚重心下沉，脚下有滑步；刺客攻击前有一个短促的吸气。
声音：短刀刮过刀鞘的金属声；木架断裂；灰尘落下。
环境反馈：木架倒下后，窗外月光从缺口照进来，地面多一道光。

【镜头 2｜3.2–6.4】中景，35mm，手持跟拍
画面：刺客稳住，二次扑上；沈砚转身，刀鞘横击刺客手腕；短刀脱手，
插入地面。
表演：沈砚转身时肩先动、胯跟上；刺客手腕被打偏，身体失去平衡。
声音：衣袖破风；短刀入地的闷响；两人急促呼吸。

【镜头 3｜6.4–10.0】近景，85mm，固定
画面：沈砚停手，胸口起伏，低头看地上的短刀，没有补刀。
表演：呼吸可见；握刀的手松了半寸；抬眼看向门外。
对白：沈砚喘息着，压低声音：“谁让你来的。”
光线：月光逆光勾轮廓；破灯笼暖光从右前方照局部；光比 6:1。

【受击反馈】
00:01.8 | 刺客右肩 | 被刀鞘推力带偏，后退两步，撞翻木架
00:05.6 | 刺客右腕 | 手腕外翻，短刀脱手，身体向左失衡

【段尾帧】沈砚抬眼看向门外，手握刀鞘，胸口起伏。
【负面】慢动作僵硬，关节反折，武器穿模，敌人呆站排队，轮流上前挨打，
无受力浮空，打击绵软，撞击无碎片，结尾摆 pose，字幕，水印。
```

## 模板 D：过场/蒙太奇（4–6 秒）

过场只做一件事：交代时间、空间或情绪变化。不要塞剧情。

```
【段号】D05
【时长】4 秒
【镜数】2
【画面】空镜：雨落在祠堂门槛，水面映出长明灯；切：一只手把染血的白布
浸进铜盆，水慢慢变红。
【光线】冷蓝雨光 + 暖黄灯火，光比 5:1。
【声音】雨声、水滴、布料入水。
【对白】无。
```

过场不要超过 1 段。每集最多 2 个过场。

## 段内时间码

每镜必须写清起止，不要只写“然后”。时间码的作用是逼你分配动作，不是给剪辑看的。

```
0.0–1.0  起势
1.0–2.0  动作发生
2.0–3.0  结果/反应
```

8 秒段里，一个动作链占 2–3 秒，剩下时间给反应和台词。不要把 8 秒塞满动作。

## 台词气口表（有对白必填）

| 项 | 内容 |
|---|---|
| 原句 | “我知道你当年做了什么，你以为藏得住？” |
| 拆法 | 拆成 3 段：①我知道你当年…… ②做了什么。 ③你以为藏得住？ |
| 气口 | ①后停 0.5 秒，手指转杯沿；②后停 0.3 秒，抬眼看对方 |
| 悬念 | ③说到“藏得住”前停半拍，不说完就切 |
| 接话 | 对方在③前插“够了”，被打断 |

气口不是空白，是人物在做事。写不出动作，就说明这个气口不必要。

## 节奏表

```
时间        节奏        运镜        目的
0.0–2.0     慢          固定        压住情绪
2.0–4.0     中          缓慢推近    逼近真相
4.0–6.0     快          正反打      冲突升级
6.0–8.0     停          固定        留白/卡点
```

一段内至少有一次快慢变化。全程一个节奏，观众会困。

## 四大铁律自检

1. **因果**：谁从哪来 → 想做什么 → 怎么受阻 → 结果是什么。
2. **物理**：重量、惯性、反作用力、碎片、灰尘有没有体现。
3. **层次**：前景/中景/背景是否至少两层有信息。
4. **留白**：段尾是否给下一段留了动作或视线。

## 光影强化

每段写清：

- 主光来源与方向（窗、烛、灯、月光、屏幕）。
- 辅光与轮廓光。
- 光比与暗部细节。
- 实用光源是否入画。
- 动作/破坏后光线怎么变（门被撞开、灯被打翻、木架倒下露出月光）。

光影变化要绑定物理事件，不要凭空变亮变暗。

## 负面约束

文戏：

```
表情僵硬，念稿感，眼神空洞，假笑，说话时身体不动，点头机器，
口型不符，面部 AI 感，字幕，水印，画面闪烁
```

打戏：

```
慢动作僵硬，关节反折，武器穿模，AI 隐性降速，动作插值柔化，
站桩蓄力，招式间长停顿，结尾摆 pose，敌人呆站排队，扎堆穿模，
轮流上前挨打，无受力浮空，打击绵软，敌人无身体形变，撞击无碎片
```

古装追加：

```
眼镜，手表，手机，电线，空调，塑料，拉链，现代建筑
```

## 段级常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 8 秒写 6 个动作 | 动作糊成一团 | 只留一个动作链 |
| 一段里两次情绪反转 | 表演断裂 | 拆成两段 |
| 三个角色同框说话 | 脸崩、视线乱 | 两人同框，第三人画外 |
| 台词 40 字 | 口型对不上 | 拆成 2–3 段 |
| 没有段尾帧设计 | 下一段接不上 | 结尾停 0.3 秒在清晰姿势 |
| 每段都换光线 | 像不同剧 | 全片统一画风后缀与主光逻辑 |
| 过场太多 | 节奏拖 | 每集 ≤2 个过场 |
