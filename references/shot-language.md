# 分镜与镜头语言

分镜不是把台词切成镜头，是把情绪变化切成**可拍摄、可生成、可剪辑**的单位。

## 每一镜先回答四个问题

1. **谁在看？** 观众此刻站在谁的角度。
2. **看什么？** 这一镜唯一的信息焦点是什么。
3. **为什么现在切？** 上一镜给了什么，必须在这一镜得到回应。
4. **切完得到什么？** 新信息、情绪变化、空间关系、节奏停顿，至少占一个。

四问答不出来，这一镜就是废镜。

## 从一场戏到分镜：六步

1. **定争夺物**：这场戏两个人/两方各自要什么？只能有一个具体物件或决定（签不签、给不给、认不认）。
2. **标节拍**：按“起、压、破、收”标出情绪变化点，不要按台词切。
3. **选信息焦点**：每个节拍只给一个焦点——脸、手、道具、空间、旁观者。
4. **搭覆盖**：主镜、双人镜、过肩、反应、插入，至少凑出一组能剪的素材。
5. **合成段**：把同地点、同光线、同情绪的连续镜合并成 4–12 秒的段。
6. **补表演与光**：每镜写微表情/小动作/视线、主光方向、台词气口，再打可生成性分。

顺序不要反。先想“这场戏在争什么”，再想“怎么拍”；先搭覆盖，再写漂亮句子。

## 调度：三条线

调度不是让人物走来走去，是用身体位置讲权力关系。

**权力线**：谁站谁坐、谁高谁低、谁在门边、谁被围在中间。权力反转时，位置要变：被俯拍的人站起来，或走到窗边逆光。

**距离线**：靠近是压迫/亲密，后退是退缩/拒绝。两人之间隔一张桌子，和隔三步，是两种关系。

**道具线**：关键道具在谁手里，什么时候交接。道具的转移就是权力的转移：印章、合同、手机、酒杯、刀。

竖屏双人调度：

- 用前后景，不要左右并排（横向空间不够）。
- 过肩镜：前景肩膀占画面 1/4，后景人脸在三分线。
- 侧面双人：两人一左一右，身体相对，中间留一条缝给光。
- 一人坐一人站：站的人俯视，坐的人仰视，天然权力差。

每一次走位都要改变权力、距离或道具归属。没有变化的走位是废动作。

## 分镜表字段

CSV 模板见 `assets/templates/shotlist.csv`。字段口径以脚本 `scripts/validate-shotlist.ps1` 为准。

| 字段 | 必填 | 写法 |
|---|---|---|
| 场次 | 是 | `S01`，同一地点时间 |
| 段号 | 是 | `D01`，一次模型调用；同段内镜头连续 |
| 镜号 | 是 | `S01-01`，场内连续 |
| 时长(秒) | 是 | 1.5–6；对话镜 2–4；情绪长镜 5–6 |
| 景别 | 是 | 大远景/远景/全景/中景/中近景/近景/特写/大特写 |
| 焦段 | 建议 | 24/35/50/85/100mm |
| 机位高度 | 建议 | 平视/略低/低角度/高角度/俯拍 |
| 运镜 | 是 | 固定/推/拉/摇/移/跟/升降/手持/环绕；写“从哪到哪” |
| 构图 | 是 | 三分法/居中/引导线/框架/前景遮挡/低角度/高角度 |
| 画面内容 | 是 | 谁、在哪、做什么、动作结果；只写镜头能拍到的 |
| 表演指导 | 是 | 微表情、小动作、停顿、视线；按 `performance-direction.md` |
| 潜台词 | 建议 | 这一镜人物真正想要什么，不给观众看，给表演用 |
| 说话人 | 有台词必填 | 角色名 |
| 台词 | 有台词必填 | 原话；目标 ≤12 字，硬上限 18，超了拆镜 |
| 语气/气口 | 有台词必填 | 低声/压着怒/气息不稳；哪儿停、停多久、停时做什么 |
| 场景 | 是 | 地点 + 具体空间特征 |
| 时间 | 是 | 日/夜/黄昏/清晨；光线状态 |
| 光影 | 是 | 主光方向 + 色温 + 光比 + 氛围 |
| 道具/服化 | 建议 | 这一镜必须连续的道具、服装、伤痕 |
| 标记 | 是 | 普通/钩子/反转/情绪最高点/结尾悬念 |
| 可生成性 | 是 | 0–100，见下文评分 |
| 参考图 | 是 | 角色/场景/道具资产编号，如 `CH_SY_v03,SC_CT_v01` |
| 备注 | 否 | 需要模型特别注意的点 |

## 景别：信息量与情绪距离

| 景别 | 观众得到 | 适合 | 建议时长 |
|---|---|---|---|
| 大远景 | 地理、孤立、命运 | 开场、结尾、转场 | 2–4s |
| 远景 | 空间关系、人物位置 | 定场、群戏、动作全貌 | 2–4s |
| 全景 | 全身动作、身体语言 | 打斗、跪拜、离开 | 2–5s |
| 中景 | 对话、关系、上半身动作 | 正反打主力 | 2–4s |
| 中近景 | 表情 + 手部 | 竖屏对话主力 | 2–4s |
| 近景 | 情绪变化 | 反应、决定、台词落点 | 2–5s |
| 特写 | 细节、道具、手 | 证据、信物、伤口 | 1.5–3s |
| 大特写 | 一个点：眼、泪、刀刃 | 峰值、卡点 | 1–2s |

竖屏里，中近景和近景是主力。全景和大远景只用来交代，不要连续使用。

## 焦段：透视就是态度

| 焦段 | 透视 | 用途 | 注意 |
|---|---|---|---|
| 24mm | 空间被拉开，人物显小 | 定场、狭小空间、压迫 | 脸会变形，不要怼脸 |
| 35mm | 接近人眼，环境与人物兼顾 | 双人戏、走位 | 竖屏裁切后仍可用 |
| 50mm | 平实、客观 | 中景、对话 | 最安全的主力焦段 |
| 85mm | 压缩空间，背景虚化 | 近景、情绪、隔离 | 适合竖屏人脸 |
| 100mm macro | 极浅景深 | 道具、信物、伤口 | 对焦难，生成易糊 |

一部戏固定 2–3 个焦段，形成视觉性格。甜宠用 50/85，权谋用 35/50，悬疑用 24/50，打戏用 24/35。

## 机位高度：谁有权力

- **平视**：平等、客观，默认。
- **略低**：人物稍显强势，不夸张。
- **低角度**：压迫、威严、反派登场。
- **高角度**：弱小、被审视、失败。
- **俯拍**：命运感、孤立、被围困。

同一场戏里，权力反转可以用机位高度完成：前半段女主被俯拍，拿到证据后切平视或略低。这比台词更有效。

## 运镜：每一个移动都要有理由

| 运镜 | 动机 | 写法 |
|---|---|---|
| 固定 | 对峙、观察、让表演说话 | 固定机位，不晃 |
| 推 | 逼近真相或情绪 | 从中景缓慢推至近景，2 秒完成 |
| 拉 | 孤立、揭示环境 | 从人脸拉到全景，露出空荡的房间 |
| 摇 | 连接两个信息 | 从人脸摇到桌上的信 |
| 移 | 跟随视线或空间 | 横移经过门框，带出第二个人 |
| 跟 | 动作、追逐、临场 | 手持跟拍，保持人物在画面中 1/3 |
| 升降 | 权力变化、揭示 | 从桌面升到人物脸部 |
| 环绕 | 顿悟、独处、仪式 | 半圈即可，不要整圈 |
| 手持 | 战争、崩溃、追逐 | 幅度小，否则脸糊 |

禁止“推拉摇移跟全来一遍”。一镜一个运动。模型对复合运镜的完成度很差。

## 构图：每镜选一个

- **三分法**：人物在左/右 1/3，视线方向留白。对话、常规叙事。
- **居中对称**：权威、仪式、对峙。压迫与秩序。
- **引导线**：走廊、剑刃、桌面边缘指向主体。
- **框架**：门、窗、廊柱框住人物。被困、窥视。
- **前景遮挡**：隔肩、树叶、柱子。层次与偷看感。
- **低角度**：权力。
- **高角度**：脆弱。
- **倾斜（Dutch）**：失衡、疯狂。悬疑慎用，一部戏不超过 2 次。

竖屏构图额外规则：

- 人脸中心放在画面上 1/3，不要顶天。
- 底部 18% 留给字幕和平台 UI，不放关键信息。
- 双人对话用“前后景”而不是“左右并排”，竖屏横向空间不够。
- 群戏用“一个清晰主体 + 背景虚影”，不要试图塞满人。

## 覆盖：一场戏至少拍到的六种镜头

1. **主镜**：交代空间与人物关系（全景/中景）。
2. **双人镜**：两人同框，确立轴线。
3. **过肩 A**：带 B 的肩膀看 A。
4. **过肩 B**：反向。
5. **单人反应**：听的一方，必须有变化。
6. **插入镜**：手、道具、证据、伤口。

生成时不必六种全做，但剪辑需要选择权。只有正反打、没有插入镜，节奏会很干。

## 轴线与视线

- 两人之间画一条假想线，摄影机始终在同一侧。
- A 面朝画左，B 面朝画右；反过来就是跳轴。
- A 看画左，B 必须出现在画左；否则观众以为他在看别人。
- 越轴必须用中性镜过渡：正面双人、空镜、运动穿过。
- 三人以上，先确立“主轴线”，第三人用过肩或单独镜。

生成时的写法：`A 在画面左侧，身体朝右；B 在画面右侧，身体朝左；两人视线相接`。空间锚定比“对峙”有效。

## 节奏：切多长

| 段落 | 单镜时长 | 切法 |
|---|---|---|
| 冲突对轰 | 1.5–2.5s | 正反打，短句，卡在对方开口前 |
| 信息揭示 | 2–3s | 台词 → 反应 → 道具特写 |
| 情绪戏 | 4–6s | 固定长镜，让表情完成变化 |
| 打斗 | 1–2s | 全景动作 → 特写受力 → 结果 |
| 过场 | 2–3s | 空镜或动作特写，不超过 1 个 |
| 卡点 | 1.5–2s | 大特写 → 黑场/硬切 |

同一景别不要连续超过 3 镜。连续 5 个中景对话，观众会疲劳。

## 可生成性评分（0–100）

分镜写完，每镜打分。**低于 60 必须改写，60–74 简化，75 以上才生成。**

| 维度 | 分值 | 高分（满分） | 中间 | 低分 |
|---|---|---|---|---|
| 同框人数 | 25 | 0–1 人 | 2 人（20） | 3 人（10）/ 4+（0） |
| 动作复杂度 | 25 | 静态或单一动作 | 2–3 个连续动作（18） | 身体接触打斗（10）/ 特技混战（0） |
| 手部与道具 | 15 | 手不做精细动作 | 握大件、递物（12） | 系扣、写字、转剑花（4） |
| 台词量 | 15 | 无台词 | ≤10 字（12） | 11–18 字（7）/ >18 字（0） |
| 环境难度 | 20 | 简单内景 | 自然外景（16） | 雨雪火水、人群（8）/ 镜面、文字、动物、儿童（0–4） |

评分不是给模型看的，是给导演看的：**它逼你在写分镜时就想清楚这一镜能不能生成**。

## 低分镜头的改写手法

| 问题 | 改写 |
|---|---|
| 三人同框 | 改成“两人 + 第三人画外音”，第三人单独反应镜 |
| 复杂打斗 | 拆成“攻击 → 受力 → 结果”三镜，接触瞬间用特写和声音 |
| 精细手部 | 换中景，手部只做“握住/放下/递出” |
| 长台词 | 拆成两镜，中间插对方反应 |
| 人群 | 背景虚化 3–5 个剪影，主角在清晰前景 |
| 雨雪 | 改成“雨后湿地反光 + 屋檐滴水”，保留氛围、降低难度 |
| 镜面/照片/文字 | 用道具特写代替，避免模型生成可读文字 |
| 儿童/动物 | 改为背影、画外声、局部（小手/尾巴），不做正脸主戏 |
| 快速转身 | 拆成“起身 → 转身 → 新机位”，不要一镜完成 |
| 吃东西/亲吻 | 用遮挡、侧脸、手部或反应镜替代 |

改写后剧情信息不能丢。丢信息的改写是偷懒。

## 竖屏与横屏

- 竖屏默认 9:16，人物占画面高度 50–70%，不要大面积空景。
- 横屏 16:9 才适合大远景、群戏、宽银幕构图。
- 同一部戏不要混画幅；用户要横屏就全片横屏。

## 分镜自检 12 问

1. 这一镜删掉，剧情或情绪会损失吗？
2. 这一镜的信息，观众能在 2 秒内读到吗？
3. 同框是否超过 2 张正脸？
4. 动作是否只有一个主动作？
5. 台词是否 ≤12 字（最长 18）、能在时长内说完？
6. 轴线是否守住？视线是否对得上？
7. 道具/服装/伤痕是否接上一镜？
8. 光影方向是否和上一镜一致？
9. 景别是否和前后有变化？
10. 这一镜是“说”还是“演”？能不能改成演？
11. 可生成性是否 ≥75？
12. 这一镜是否服务于六拍中的某一拍？

## 镜头语言的底线

- 不要用运镜代替调度。人物走位比镜头花活更重要。
- 不要用特写代替表演。特写只能放大已经存在的情绪，不能创造情绪。
- 不要用空镜凑时长。空镜必须承担时间跳跃、空间交代或情绪留白之一。
- 不要让每镜都“好看”。分镜要服务叙事，漂亮但没信息的镜头是噪音。
